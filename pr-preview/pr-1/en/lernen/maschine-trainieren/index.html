At the animal shelter: dog or cat?

In the card game you found a rule yourselves. Now a machine gets the training bag. It should tell the animal shelter whether a new animal is a dog or a cat.

On this page you learn how the machine decides from the cards in the bag. Then you fill the bag yourself so that it decides correctly.

How the machine decides

The machine does not look for a rule like you did in the card game. It compares the new animal with every card in the bag and counts the features they have in common. The card with the most features in common is the most similar example. The machine gives the new animal the label of that card.

Krümel compared with the cards in the bag. ✓ means: the same as Krümel, ✗ means: different.

Luna is the most similar example. So the machine says: cat. That is wrong, Krümel is a dog. The machine did not count wrong. The bag is just missing an example like Krümel: a small dog with pointed ears.

nearest neighbour

The example in the bag that is most similar to a new animal. A machine that decides like this uses the “nearest neighbour” method.

Remember

  • In the card game you find a rule. The machine looks for the most similar example. Both learn only from what is in the bag.
  • If a cat is just as similar as a dog, the machine says: I don't know.

With JavaScript you can put animal cards into the training bag here and choose a new animal. For each card in the bag the machine counts the features in common and gives the new animal the label of the most similar card. At the start the bag holds Luna (cat) and Bruno (dog), and the new animal is Krümel (dog: pointed ears, short snout, small, round pupils). Luna has 3 features in common, Bruno 1: the machine says “cat”. If you add Sammy (dog: pointed ears, short snout, big, round pupils), Sammy also has 3: the machine does not know. If you take Luna out and put Tiger in (cat: pointed ears, short snout, big, narrow pupils), Tiger has 2 and Sammy 3: the machine says “dog”.

Looking back

You have trained a machine. Nobody programmed a rule for dogs and cats into it. It only got examples with labels and decided from them. This is called machine learning.

What goes into the bag decides what comes out. With good examples the machine decides correctly, with missing examples it makes mistakes.
